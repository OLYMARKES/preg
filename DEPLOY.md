# GitHub Pages deployment

Пакет готов к отдельному репозиторию `OLYMARKES/pregnancy-cover-team-constructor-pages`.

1. Создать репозиторий с согласованной видимостью.
2. Отправить эту папку в ветку `main`.
3. В **Settings → Pages** выбрать **GitHub Actions**.
4. Workflow `.github/workflows/pages.yml` опубликует `index.html`, шрифты, data-файлы и 94 production-safe изображения.

Перед публичной отправкой требуется отдельное подтверждение владельца фотографий: GitHub Pages и публичный GitHub-репозиторий делают вложенные изображения доступными по прямым URL. Чувствительные кадры уже исключены технически.
